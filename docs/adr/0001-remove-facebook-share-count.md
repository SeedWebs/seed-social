# ตัดยอดแชร์ (Share count) ออก แทนการย้ายไปดึงยอดฝั่งเซิร์ฟเวอร์

รุ่น 2.0.0–2.0.6 แสดงยอดแชร์บนปุ่ม Facebook โดยพิมพ์ Facebook App ID และ App Secret ของเจ้าของเว็บลงทุกหน้า (เข้ารหัสแค่ base64) ให้เบราว์เซอร์ของผู้เข้าชมเรียก Graph API ด้วย access token `APP_ID|APP_SECRET` App Secret จึงกลายเป็นข้อมูลสาธารณะ ในรุ่น 2.0.7 เราตัดยอดแชร์ออกทั้งหมดแทนการย้ายการเรียก Graph API ไปฝั่งเซิร์ฟเวอร์ เพราะทางนั้นจะเพิ่ม outbound request ใหม่จากทุกเว็บ (กติกาของรุ่นนี้ห้าม ถ้าไม่ได้รับอนุมัติชัด ๆ) ยังต้องเก็บและใช้ App Secret ต่อ และต้องมี cache เพื่อไม่ให้หน้าเว็บช้า

## ทางเลือกที่พิจารณา

- ตัดออก (เลือกทางนี้): ไม่มี request ใหม่ และปิดช่องโหว่ได้ทันที เสียแค่ตัวเลขบนปุ่มของเว็บที่กรอก App ID/Secret ไว้
- ดึงยอดฝั่งเซิร์ฟเวอร์ด้วย `wp_remote_get()` และ transient: secret ไม่ออกไปหน้าเว็บ แต่เพิ่ม request ใหม่และงานดูแลต่อเนื่อง

## ผลที่ตามมา

- ไม่ลบและไม่เปลี่ยนชื่อ option `seed_social_app_id` กับ `seed_social_app_secret` ค่าเดิมอยู่ในฐานข้อมูลต่อ ย้อนรุ่นได้ และปลั๊กอินไม่ลบข้อมูลของผู้ใช้เอง
- หน้าตั้งค่าแสดงสองช่องนี้เฉพาะตอนที่ยังมีค่าเก่า พร้อมข้อความให้ reset secret แล้วลบค่า เพราะเว็บที่เปิด auto-update จะไม่เห็น Upgrade Notice เมื่อลบค่าจนว่างแล้ว ช่องจะหายไปเอง
- คง `<span class="count"></span>` ไว้ในปุ่มแบบว่าง เพราะ CSS ของธีมและตัวอย่างใน FAQ อ้างถึง
- ถ้าจะกลับมาแสดงยอดแชร์ในอนาคต ต้องทำฝั่งเซิร์ฟเวอร์ และต้องขออนุมัติ outbound request ใหม่ก่อน
